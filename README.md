# Fireworks Shop Kenya Category Page Template

## Overview

This repository contains the master category page template used across Fireworks Shop Kenya.

The template provides a consistent structure, design, and user experience for all product category pages while allowing category-specific content.

## Main Points

* Reusable category page template
* Consistent layout across all the page categories
* It's a suggested template by Zameer Noorali on 18th June 2026
* Responsive design for desktop, tablet, and mobile devices
* It was implemented by Yusuf Abdulkarim
* Easily customizable category content sections

## How It Works

The template acts as a single source for all category pages.
On the category page there's two WYSIWYG editor one is for the main description and the other is for Bottom Category content
NB: It should be used only in the WYSIWYG

### Product Population

On products population products are automatically displayed within the category grid based on their assigned category in WooCommerce.

When a product is assigned to a category through the Product Editor:

1. The product is linked to the category.
2. WooCommerce retrieves the product data.
3. The template automatically displays the product in the corresponding category grid.

NB:No manual product insertion is required within the template.

## Template Structure

The template contains:

* Hero Section
* Category Introduction
* Product Grid
* SEO Content Sections
* H2 / H3 Content Blocks
* FAQ Sections
* Call-to-Action Areas

The structure remains consistent across all categories while the content can be customized independently.
